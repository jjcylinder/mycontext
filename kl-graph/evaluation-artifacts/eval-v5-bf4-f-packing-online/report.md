## 新证据去了哪里

- **BF18 的改善出现在周报部分。** 优化版交代了周报请求只查文档、待回签消息在索引中可查，因而周报这一要点由不全变为完整。两版原输入均有 XWR1-05 支持这两项。优化版单独补进的 XSH2-07 说明晨报消息后来已可检索，但答卷只说旧快照看不到消息、已登记新快照重跑。两版也都没有明确说明晨报和周报可复用同一套来源核查方法。[原版答卷](BF18-A.json) · [优化版答卷](BF18-B.json)
- **BF13 有一项能直接对上新增依据。** 优化版写出阿语导出模板的 12 个 Word 格式样例复测通过，对应新增的 NTR-S02。它还写了数据吴工负责消息和文档采集，却没有把数据侧明确分配给本题某个具体未决事项，因此原子项 7.3 未得分。两版都有固定摘要六例和周报要点，完整业务要点均为 2/7。[原版答卷](BF13-B.json) · [优化版答卷](BF13-A.json)
- **BF07、BF20 本轮均答全。** 前者保留了公函预演样例、签署人缺陷、输出检查和正式模板的区别；后者保留了汇报局部结果和限定范围的口径，并说明统一日期、总通过率及模型提升值为何不能承诺。两题检查退步的结果只覆盖本次作答。[逐项评分与答卷位置](atom-review.csv)

## 实验口径与判断

事前固定两道离线输入有增益的题（BF18、BF13），另选两道原版首次作答即满分且业务内容不同的题（BF07、BF20）。原版输入哈希逐题核对历史归档，优化版直接使用离线归档的冻结输入。两版走同一 ChatGPT Codex 默认桥接、low 推理、1,800 token 输出预算请求，以及 8,192 token 证据预算。默认桥接使用服务端选择的具体模型。每题每版各答一次，8 份均首次通过结构和引用 ID 校验。作答请求不含评分标准。

评分时只查看题号、匿名答卷与既有原子评分标准，按答案中的实际文字逐项记录，之后再揭示版本。评分由本次助手完成，未经独立业务评审。完整要点要求其所有原子项得分。沿用 BF20 既有评分口径，答卷交代固定六例和配置、换配置须重新核验，可以覆盖限定范围。BF13 对群聊中已记录的局部复测予以计分，保留对环境归属的限定。

**暂保留原版 F。** 本轮观察到局部答卷改善，两个检查退步的样本均保持满分。选题有意包含两道输入已知改善的题，每份输入仅生成一次，无法把已有依据在新答卷中被写出的差异归因于装入方式，也不能据此推算 20 题整体答全率。
