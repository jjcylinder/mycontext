- **X01 的分工信息在筛选后丢失。** 六份职责材料 ATR0-S04、ASU0-S04、AAM0-S04、ALE0-S04、AWR0-S04、APO0-S04 均进入两边的候选和排序结果。B 最终保留 28 条来源，用去 8,142 token，六份分工材料全部落在回答输入之外。C 保留 54 条，用去 8,192 token，六份职责材料悉数入选并被答案逐项引用。C 的 54 条中有 38 条使用事实定位的原文节选。这一题的最终输入中，额外附加的事实和关系文本均为 0。直接观察到的增益是同一预算下，更多可追溯证据抵达回答阶段。单次 B/C 对照无法拆分事实定位、图谱召回与排序各自的贡献。
- **X03 的语言分支证据也能追到筛选阶段。** A03-S02 和 ATR1-S04 在 B 中均进入候选及排序，但最终均未入选。B 最终选入的原文没有指明 TR-X02 或 TR-X03。C 两条均保留，答卷据此区分已验证和待回归的分支。
- **PO03 仍是 C 的缺口。** C 的回答输入包含 XPO2-03，原话说明两个集合“口径不同，也不都检查事实”，足以支持拒绝合计，但没有给出两组样本的交集。两边都解释了检查维度不同，也都没有明说材料不足以判断样本是否重叠。仅看这条证据的召回状态会高估答卷完整度。
- **TR04 的 B 有证据基础。** ATR0-S04、ATR1-S04、ATR2-S03 已进入 B 的最终输入，覆盖测试组织整体回归、模型样本缺项及异常分支边界。B 提到了语义风险，也指定了测试负责人，但将明确的语义核查挂在切包条件下。按本题要求，缺的是测试职责与正常译义回归之间的明确对应。
