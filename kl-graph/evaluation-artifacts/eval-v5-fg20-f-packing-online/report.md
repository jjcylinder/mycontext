# 优化版 F 在 FG01–FG20 上的线上验证

本轮对 FG01–FG20 的优化版 F 输入各调用一次线上 ChatGPT，20 份均首次通过结构与引用 ID 校验。使用与此前相同的 V5 模拟数据、问句、冻结评分项、8,192 token 证据预算、项目默认 ChatGPT 桥接、low 推理设置和 1,800 token 输出预算请求。原版 F 列取此前正式 FG 评测归档，优化版列为本轮新答卷。按原口径，答卷中明确写出且有输入依据的原子项才得分；一个完整业务要点所含原子项须全部得分。由本次助手按答卷文字审核，可按文末指针复核。

- **FG18 新证据进入了答案。** 优化版根据 D07-S02 写出了“邮电部阿语公文写作”，由 5/7 升至 6/7。输入仍缺法语文档翻阿语的记录，因此场景列举这一要点仍未答全。
- **FG01 答卷从 6/10 升至 8/10，完整要点从 0/3 升至 1/3。** 新答卷写出了周报请求只查文档、待回签消息在索引中可查。这两项在两版输入中都有依据。优化版另外装入的 XSH2-07 明确晨报消息后来可检索，此项依然漏答；答卷也没有明确说明两个缺陷可以复用来源核查方法。FG01 与 BF18 同问，本轮重新作答。
- **FG07 从 8/8 回落到 7/8，完整要点从 3/3 降至 2/3。** 答卷分别说明六条为风格评审、两条为数字日期检查，也指出不能直接相加，但遗漏“两组是否重叠、去重后有多少样例无法确定”。输入仍支撑 8/8。这是唯一从答全变为未答全的题。
- **FG06 维持 9/10。** 答卷写了润色调用“进入润色 Skill”，引用的原稿、输出和群回复可以证明任务要求及“有 Skill 进入”，却不足以证实该次调用的实际入口就是 doc-polisher。直接记录入口的 APO1-S03 仍未装入；按原评分口径，第 2.1 项不得分。

其余 16 题的两版答卷均覆盖全部原子项。优化版通过了输入完整性验收，本轮没有观察到整套答卷完整性的提升。对照使用历史原版答卷，每种输入只有一次纳入此次对照的作答，FG07 的单次回落无法区分装入方式的作用与模型作答波动。
