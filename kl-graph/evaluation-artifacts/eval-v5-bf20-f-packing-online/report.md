# 优化版 F 在 BF01–BF20 上的线上验证

20 题均以优化版 F 的冻结输入重新调用线上 ChatGPT，首次作答均通过结构和引用 ID 校验。题目、V5 模拟数据、原子评分标准及 8,192 token 输入预算与归档一致。回答使用项目默认 ChatGPT 桥接、low 推理设置和 1,800 token 输出预算请求。逐项复核最终交付的答卷，以实际文字标记得分位置。原版 F 取此前 BF 二十题正式归档的可交付答卷，BF08 按既有规则计入一次相同输入的重试。本轮重新生成全部答卷，包括此前小规模复测用过的题。

**整题通过数持平，答全的题发生了变化。** BF04（SU04）从 5/6 增至 6/6，本次明确写出换候选模型后应重验固定六例及受影响的 Skill。BF11（PO03）从 8/8 降至 7/8，只说明六条风格评审和两条数字日期检查不能相加，没有说明两组样例是否重叠、去重后有几条无法确定。两题的原版、优化版输入均足以答全。BF11 与 FG07 的优化版输入指纹一致，两次分别作答均漏了交集未知。

**新增输入依据有一项在本轮成为新增答分。** BF13（X01）写出了 12 个 Word 翻译样例格式复测通过，由 18/31 上升至 19/31。答卷也列出了数据侧的采集职责，但没有将数据侧对应到具体未决事项，完整业务要点仍为 2/7。BF18（X06）从 6/10 增至 8/10，明确周报仅查文档、待回签消息在索引中可检索，补齐一个完整业务要点。两版输入本来都支持这两项。新增的“晨报消息后来可检索”仍未写出，两项缺陷可复用来源核查方法也被遗漏。

其余 16 题的答卷覆盖数持平。BF02 仍缺损坏附件分支回归；BF10 虽写明预演去重已测、正式包未切，也交代下轮目标包未定，但没有把核实实际运行包列为回归检查，按原评分口径未得该分。本轮达到既定的两项输入验收条件，答卷原子项和完整要点也有小幅提升。历史对照与本轮每题各计一份答卷，答卷差异可能包含模型作答波动。
