## 证据在哪一步丢失

上一轮 high 的 B 和 C 都保留了 ATR0-S04，原文登记了应用提供译义期望答案、模型分析、测试组织整体回归。本轮 333 条候选仍含该来源，但 B 的初筛未推荐，C 复用了相同三批初筛，后续也未补回。单次选证输出峰值离 4096 尚有余量，实际没有截断。D08-S02 上轮 C 入选、本轮两组均未入选；两份新答卷均未重复要求提交模板，但不能由此推断模型已能稳定处理这条原文。

C 仍保留 ATR1-S04 的 TR-X03 未回归和 XTR3-07 的发布申请边界，也用等价材料支撑了模型分析。上轮 C 还能够交代应用提供期望答案的已登记职责。本轮关闭选证思考的收益体现在耗时；对本题而言，源自初筛的责任遗漏足以影响执行。单题、单次结果不足以支持推广为默认设置。

## C 的根因复核

此前“初筛漏选，后续也未补回”的描述省略了关键一步。C 的图谱确实把 ATR0-S04 补进了全局重排输入。归档显示如下。

| ATR0-S04 经历的阶段 | 上轮 C，high | 本轮 C，关闭选证思考 |
|---|---|---|
| 初筛输入 | 进入同一批 144 条原文 | 进入同一批 144 条原文 |
| 初筛推荐 | 3 个组含该来源 | 0 个组含该来源 |
| 全局重排输入 | 64 条中包含它 | 120 条中包含它 |
| 全局重排输出 | 2 个组保留它 | 15 个输出组均未保留 |
| 全局后的遗漏复核输入 | 包含它 | 110 条中未包含它 |
| 最终答案输入 | 包含它 | 未包含它 |

**事实抽取与图谱。** 该来源有四条成功定位到原文的 DELEGATE 事实。两轮全局重排都收到了相同的职责原句，并有三条来自该来源的图谱事实提示，其中明确写了应用提供期望答案、模型林工分析、测试陈工组织整体回归。本轮全局重排保留了“模型在等判定材料”，给该组标上“责任分工”，却丢掉了“谁提供材料”。它还分组保留了摘要限定六例等旁支。可以观察到选材重点发生变化；日志无法单独测出候选变多与推理配置各自的影响。[本轮全局重排实际请求与响应](../../data/project_demo/v4-deepseek-runtime/model_calls/b837eb7b692c4252b12f778d9094f74d.json)

**遗漏复核。** 复核只从初筛已推荐且优先级至少为 2 的证据组中构造遗漏清单。来自图谱、进入全局输入又被全局丢弃、且初筛没有推荐的来源，不在该清单里。已有的事实补证逻辑针对适用范围和局部验证，这道问“四方分别需要协调什么”的问题也没有触发它。[遗漏清单实现](../../project_demo/selection.py#L355) · [限定范围补证入口](../../project_demo/fact_evidence.py#L122)

**预算离线对照。** 用相同构造函数逐字重建本轮最终提示，得到相同的 7908 个估算 token。仅追加上一轮已使用的 ATR0-S04 原文节选和来源元数据，输入变为 7998/8192，增加 90 个 token，无需移除其他资料。这项对照验证了证据放得下，未验证模型看见它后一定答对。

**回答归因。** 最终模型把提供材料、分析缺陷、安排回归写进同一条 action。该项的六条引用支持“模型还要分析”和“缺期望答案、判定说明”，均未指定“测试/业务补齐”。答卷却给出了这一分工。现有引用检查核对引用是否来自输入，无法验证某个动作是否确由所写责任方承担。[本轮 C 完整提示及答卷](../../data/project_demo/v4-deepseek-runtime/runs/dedbb738-50f3-448c-a091-30d0dc0941e1.json)

优先验证的修改是让分工题的遗漏检查比较每一个动作及其承担方，并覆盖有精确出处的图谱职责事实。例如，“模型等待材料”不能替代“应用提供材料”。只有实际原文支持时才填写该动作的负责人。无须把全部图谱来源机械前置，也无需重新通读 333 条候选。
