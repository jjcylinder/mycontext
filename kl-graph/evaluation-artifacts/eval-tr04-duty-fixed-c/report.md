## 实现与边界

分工核查后，C 比较最终已选原文与本次图谱查询命中的具体职责、等待材料或申请。若来源中的指代依赖直接回复，检查会验证可见性、会话与线程，将直接父消息一并加入预算。B/C 的生成要求相同，登记分工以实际传入的原句或分句呈现；校验核实引用、摘录边界以及聊天发言来源。检查可拦截部分无据归责，不能保证自由表述的所有跨句推论都正确。对“登记由哪个团队负责”“落实到哪个个人”“样本包内哪些材料有依据”三个层次，当前回答仍可能合并表达。单题也不足以推断五题准确率。
