# 固定候选选证预算离线核查

业务需要保住决定结论的原文。历史 ChatGPT/C 使用 low 推理，在默认五题完整通过的那次运行中，X01 的 AAM1-S04 和 X03 的 AWR1-S04 均进入最终输入。DeepSeek 暂无关闭思考的同输入选证记录，其关闭思考后的证据保留率仍待实测。

## TR04 的耗时差在哪

| 冻结运行 | B | C | 选证与调度 |
|---|---:|---:|---|
| ChatGPT 经 Codex CLI | 171.7 秒 | 167.9 秒 | low，初筛两批，B/C 同题并行 |
| 当前 DeepSeek Flash | 481.7 秒 | 323.0 秒 | high，初筛三批，逐题 B→C，C 的三批初筛均命中本机缓存 |

ChatGPT 历史五题的平均耗时为 B 151.6 秒、C 164.7 秒。DeepSeek 当前 TR04/B 的五次选证合计产生 74,366 个思考 token，最终回答另产生 19,223 个。全局重排和遗漏复核的思考用量分别为 20,862 和 19,161。还有模型服务吞吐、提示内容、分批和缓存等差别，现有记录不足以拆出各因素的独立耗时贡献。

## 固定输入的方法

用请求哈希和提供方 usage 匹配归档中的实际请求和响应，校验完整 JSON 中所有引用均属于该次输入，并核对最终提示中实际传入的原文。逐次分别记录总输出、思考和非思考 token。历史同版默认五题 B/C 和当前首题 B/C 共 39 个逻辑选证请求，去重后 36 个实际响应。历史轮与当前轮分开统计。每份候选的顺序摘要、逐请求哈希、归档键和被核查的原文见[明细](verified.json)。复查命令为项目虚拟环境下运行本目录的 [replay.py](replay.py)。

| 每次选证总输出上限 | 历史五题 B 可容纳原整条链 | 历史五题 C | 当前 TR04 B | 当前 TR04 C |
|---:|---:|---:|---:|---:|
| 4,096 | 0/5 | 0/5 | 否 | 否 |
| 8,192 | 0/5 | 0/5 | 否 | 否 |
| 16,384 | 3/5 | 4/5 | 否 | 否 |
| 24,576 | 5/5 | 5/5 | 是 | 是 |

表中逐题要求每一次选证响应都能装入相应上限。它衡量对已发生的 high 输出的容量。较小预算可能改变模型推理和返回的组，无法通过截断归档或沿用大预算缓存来测出。所有请求的非思考输出峰值为 1,406 token，可把 4,096 作为关闭思考时的首个试验上限。现有 110 份 DeepSeek 选证 trace 均启用了 thinking，故无法离线实测关闭后的耗时和选证质量。

## 关键证据去向

| 用例 | 同版历史五题的 high 归档 | 当前版归档或补充检查 |
|---|---|---|
| TR04 | 两组都保留 ATR0-S04、ATR2-S03。D08-S02 未进入这两组的最终提示。 | 当前 C 还保留了明确模板已提交的 D08-S02，B 未保留这条原文。 |
| AM03 | B、C 都保留旧快照来源 AAM1-S04。 | 当前 B 在暂停服务时中断，未形成有效答卷。 |
| PO03 | 两组都保留 APO0-S02、APO1-S04、APO2-S02。 | 当前没有新答卷。 |
| X01 | 两组最终输入均缺少 AAM1-S04。 | 历史 ChatGPT low 的 C 保留了它。 |
| X03 | 两组最终输入均缺少 AWR1-S04。 | 历史 ChatGPT low 的 C 保留了它。此前冻结候选、使用当前 C 的事实关联及装入逻辑，也保留了该原文。 |

以上逐条跟踪指定来源。其他来源可以支持同一要点，原文进入输入也需要回答正确使用，不能用表格给整题判分。

## 独立选证开关

本地 DeepSeek 桥接可通过 `DEMO_DEEPSEEK_SELECTION_THINKING=disabled` 单独为选证发送关闭思考的请求，通过 `DEMO_SELECTION_OUTPUT_TOKENS=4096` 设定每次选证的总输出上限。默认继承已有模型配置。缓存按模型、地址、选证设置和完整请求区分。相同候选下，改变这两个选项不会改变输入分批或最终答题配置，超过上限的响应按失败处理。本轮核验了请求构造和缓存隔离，尚未向远端提交 disabled 请求。

下一项能直接回答质量问题的实验是固定同一道题的候选、顺序、原文与分批，用关闭思考的选证重新产生各阶段的证据组。下游全局重排应读取新的初筛结果，避免复用旧组掩盖遗漏。先只比较选证时间、JSON 有效率，以及 X01 的重跑状态与 X03 的去重输入对是否有原文支持，允许等价来源。该实验需要实际调用远端 DeepSeek selector，无需运行最终答题。
