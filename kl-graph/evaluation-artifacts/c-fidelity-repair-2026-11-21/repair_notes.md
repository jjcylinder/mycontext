# 第二梯队反例修复

2026-11-21。本轮目标是在公平对照中验证C的实际增量，修复对象为LE03全局选证遗漏与X05跨句原文节选遗漏。语料、原始索引、embedding、回答模型及统一预算不变；不添加题号、参考答案或题目专用规则。

## 已实现

- `fact_evidence.py`支持带明确指代依赖的2～3句连续原文定位；同句找不到已还原的编号时，允许用前句与“该包”等后句共同提供出处，不跨远距离随意拼接编号。
- 检查每条具有精确单一来源的合格业务事实；有未能匹配的事实时，整条原文回退全文，不保留仅覆盖部分已知事实的节选。GENERAL/OPINION无编号的程序性背景仍不强制保留。记录匹配、未匹配事实ID及投影/全文回退状态。
- 相邻原文字符区间合并，前件和指代句连续展示，不在实际未省略的位置插入省略号。聊天继续保持完整。
- `selection.py`向B/C同样提供项目范围，并在全局重排后复核初筛认为直接相关或必要、但未完整保留的证据组。复核读取实际证据，检查限定、否定、例外、版本、归属及责任；不因来自图谱而优先，不因摘要理由写得完整就认为实际证据充分。
- 复核只补充有必要性的新证据组，不删除已选组；重复与无关材料不补。按模型窗口分批，无法容纳单组审计时明确保留该必要组交给统一预算装入，记录未完成审计状态，不静默丢弃。最终8192消息预算保持不变。

23项相关测试通过，排除2项涉及A的测试。覆盖跨句指代、未入集合否定、未匹配事实全文回退、不把无指代的相邻编号拼成关系、精确字符溯源、复核找回有项目限定的原文、排除背景以及审计容量不足时的显式保留。

## 评测与边界

固定第一梯队TR04、AM03、PO03、X01、X03，再固定第二梯队SU04、LE03、WR04、X05、X07。各题BC一次，共10道不同题、20份答卷，未运行A，也不是全部20题。脚本run_both.py顺序执行并保留答卷，代码指纹见implementation.json。评分仍按必要要点完整、接受等价证据；不根据本轮结果更换题目。

本轮没有开启原生实体消歧或修改图谱schema。跨句指代支持是事实定位原文机制，不能等同完整实体消歧。词语和编号覆盖不是语义蕴含证明；原生漏抽的事实或更复杂、远距离的限定仍可能影响完整性。全文回退保真但会增加输入，遗漏复核同样增加调用，均需在实际评测中报告。
