## 得分差异来自哪里

以下采用 LE04 F 同输入重试后的答卷。输入覆盖按实际装入材料能否支撑结论判定；答卷覆盖按最终文本是否表达结论判定。两组都可能装入了充分证据却只答出部分条件。

| 差额来源（F 减 B） | 输入原子项 | 答卷原子项 | 输入完整要点 | 答卷完整要点 |
|---|---:|---:|---:|---:|
| X07：摘要、公函的目标语言路径仍待回归 | +2 | +2 | +1 | +1 |
| TR03：项目 A 正式环境当前使用的语言配置 | 0 | +1 | 0 | +1 |
| PO03：两组样例的交集未知 | 0 | +1 | 0 | +1 |
| 其余 7 题 | 0 | 0 | 0 | 0 |
| **十题合计** | **+2** | **+4** | **+1** | **+3** |

B 的 68 个有依据原子项中写出了 65 个，遗漏分布在 TR03、PO03 和 SU04。F 的 70 个中写出了 69 个，仅漏 SU04。因而输入多 2 项，加上少漏 2 项，答卷共多 4 项。X07 新增的两项合计补全一个业务要点；TR03、PO03 则各补上所在要点的最后一个条件，完整要点的答卷差额为 3。

- **TR03。** 两组都能交代加密分支预演复测、损坏分支未回归、译义问题未关闭。B 输入可由正式 11 包与异常渲染器的原文组合定位旧语言配置，答卷只写正式未部署 LANG-02。F 通过事实榜第 17 的 A00-S01 直接装入正式环境配置行，答卷明确给出 LANG-01。该来源未进入原文榜前 50。

- **X07。** F 的事实榜第 9 条来源 A03-S02 直接列出损坏附件、摘要目标语言、公函目标语言仍待回归。B 可从 ATR1-S04 得到损坏分支，但未带进后两个路径的同等依据。其答卷泛称其他场景覆盖待核；F 在答案里逐一给出了两项限定。两组均区分了潜在影响与已测范围。

- **SU04。** 两组都交代了不能临场换文件和否定条件的内容风险。B 把新版本的否定与条件是否经验证列为未确认，结合另行审核要求计入文件复核项。两组均写了原应用包和模型，但均未明确换候选模型后须重新验证。F 已装入 XSH1-05 与 XSH1-06 的换模型问答，却只在答卷提到候选评测还没结束。

- **复用题 PO03、TR04。** PO03 两组输入都足以判断两组样例的交集未知，B 已说明“六条评行文、两条查数字日期，不能合并为完整通过率”。只有 F 进一步指出材料未给两组的样例对应关系，去重数也无法确定。该题的一次作答不足以判定表达差异的原因。TR04 两组都缺损坏附件的具体测试待办。两题使用的是 rank 版答卷。

本轮保留各题冻结的 3 个业务要点。新增七题依据原验收文字拆为原子项，独立检查最终输入和答卷；引用允许多条材料共同支撑，未以命中指定参考 ID 直接给分。新增答卷按甲乙标签复核，由同一助手判读。统计仅覆盖必要业务条件和能否交付，未另评附加结论。这些题来自同一项目，均为已知测试问题，每个方案每题只有一份计分答卷。
