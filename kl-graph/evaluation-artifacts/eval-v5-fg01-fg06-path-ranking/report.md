# FG01、FG06 的 G 轻量版与向量版对照

两题上，两版答卷均覆盖 **17/20 个原子项、4/6 个完整业务要点，答全 1/2 题**。向量版使 FG01 的输入首次足以回答三个完整要点，但最终交付没有增加得分。FG06 的两次调用在两版中均区分正确。向量排序在本机两题合计约 19 分 55 秒，轻量排序合计约 0.028 秒。

## 证据、耗时与评分依据

同一题仅检索一次，两个版本共享原文榜、事实榜、全部候选路径和原文节选。轻量版调用当前通用排序，向量版对同一批路径文本用本机 Qwen3-Embedding-0.6B（1024 维、两条 CPU 线程）编码，再按与问句的余弦相似度排序。均使用排名装入、图谱榜前 50、8192 token 输入预算、同一 Codex 默认回答模型配置。两个版本都使用上游向量召回。四份最终输入的指纹各异，各作答一次。只用项目 A 模拟资料，未重新建库。

### FG01　相同的答卷总分掩盖了不同的漏项

周报的关键回复 XWR1-05 写明“IM-W19在索引里能找到，但请求source_types只有document”。它在公共原文榜排第 4，两版均已装入。轻量答卷准确写出这两点，向量答卷仅说明周报漏取 IM-W19 和时间窗口有误。仅写“漏取”不能推出请求只查文档，也不能推出索引本已能搜到消息。

向量排序把晨报回复 XSH2-07 从图谱榜第 55 提到第 10，随同线程线索进入最终输入。向量答卷据此说明消息已恢复可查、原产物未重跑。轻量答卷用 XAM2-03、XAM2-06 指出旧快照漏掉截止前消息且未重跑，输入中缺了“后来可检索”的佐证。两份答卷都要求分开登记，均没有明确概括可复用的来源核查方法。向量答卷还分别提出核对晨报重跑后的补齐情况、周报修正后的风险依据，满足分别回归这一项。

本题接受“旧快照漏掉应纳入的消息”及结合上下文表达同一判断的等价说法，无需报出具体水位时刻。分别修复可由对晨报快照或补漏、周报窗口与消息源提出不同处置来表达。分别回归须能辨认两项各验什么。仅建议两张问题单互相引用，不能据此获得“复用来源核查办法”的分数。

### FG06　两版都能区分两次实际调用

轻量版装入 40 个来源，向量版装入 30 个。两版都保留了摘要 ASU1-S01 至 S03 和润色 APO1-S01 至 S03 的配对材料，均能追到各自的入口、应用包、实际输入和输出。两份答卷都把“客户未确认变成已确认”归到摘要，把“拟于变成定于、发货条件丢失”归到润色，并说明要分别排查和回归。向量版还装入 ASU2-S04、APO1-S04 等状态记录，能更直接地说明两侧均待处理。轻量版从调用对照、模型协查及待回归记录也能支持该判断。两版的输入和答卷均覆盖 10/10 个原子项、3/3 个完整要点。

本机两题的结果支持保留轻量排序为默认值。向量排序在 FG01 确实改善了最终输入。是否值得为特定场景付出这部分成本，需要看这种输入收益能否在更多未调优的任务上重复，并最终减少业务误判。

本轮仅比较两个指定题目的两种 G 排序，每个输入采样一份答卷。评分为本次按既定规则所作的逐项复核，尚未经独立业务人员盲评。
